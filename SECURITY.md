# Security policy

Report suspected vulnerabilities privately through the repository's GitHub
[security advisories](https://github.com/assurrussa/goadmin/security/advisories)
using **Report a vulnerability**. Do not include an exploit or secret in a
public issue.

The repository owner must enable GitHub private vulnerability reporting before
that button is available. If it is unavailable, contact the maintainers through
a private channel listed on their GitHub profiles rather than opening a public
issue. We have not committed to a fixed response SLA or a supported-version
matrix; each report will be assessed against affected releases.
